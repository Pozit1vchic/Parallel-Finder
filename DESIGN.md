# Parallel Finder design contract

The canonical visual specification for stage 5 lives in
[`docs/design.md`](docs/design.md). This root file exists so that a design or
coding agent finds the contract before touching QML.

Parallel Finder is a quiet editorial motion-analysis workstation. The
Parallel-Alpha prototype defines the three-column workspace and behavior;
Claude references contribute only the near-black atmosphere, typographic air,
soft depth and restrained terracotta/sage light. Do not copy the Claude login
layout or its brand mark.

Hard rules:

- true black work surface, not a screen full of grey cards;
- one large comparison stage, two equal side rails, shared outer inset;
- terracotta means A/action, sage means B/context;
- real video and timecode are the visual hero after analysis;
- empty state uses a subtle motion trace, never radar rings or fake graphics;
- all nine matcher controls remain visible through scrolling and map to
  `MotionMatcherParams`;
- settings/export are custom movable overlays with deliberate depth;
- Lucide icons only for interface icons;
- use sentence case and restrained editorial serif headings;
- no unsupported feature may be presented as complete.
