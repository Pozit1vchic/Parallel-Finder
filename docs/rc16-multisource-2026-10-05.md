# RC16.4.1: индивидуальные параллели и общая личность в нескольких SCP

Сборка текущего состояния по просьбе пользователя. Завершающий прогон видео остановлен; дополнительные проверки и проверка запуска готового пакета пропущены. Это не заключение об отсутствии регрессий. Прежние RC16–RC16.3 остаются в release.

## Изменения

- После независимого выбора главного человека внутри каждого видео выбирается одна подтверждённая физическая личность для всего набора. Лицевые признаки берутся из разных шотов; перекрывающиеся окна не дают дополнительных голосов. Все источники группы должны взаимно подтверждаться, объединения через промежуточный файл нет. Несовместимый источник исключается; статус показывает число подтверждённых видео. Порядок файлов нормализован.
- В режиме индивидуальных пар один полный шот имеет одну общую квоту для поз и движений. Дополнительный ограниченный проход ищет параллели в неиспользованных шотах по наблюдаемым конечностям. Новые движения только головы этот проход не добавляет. Стандартный предел результатов увеличен до 500; нестандартный пользовательский предел сохраняется.
- Между SCP одного человека отсекаются копии исходного эпизода: сравниваются реальные RGB-миниатюры и исходные времена нескольких последовательных кадров, с ограниченной поправкой цвета, проверкой отражения и чёрных полос. Перекрывающиеся обрезки подтверждённой копии разделяют квоту. Отдельная более мягкая проверка повторяющейся камеры применяется к параллелям головы, не к доказательству копии телесного движения.
- Личность дополнительно проверяется на фактически выбранном интервале. Лицо привязывается к измеренному положению головы выбранного трека, чтобы соседний человек или лицо на фоне не заменяли его. Крупное уверенно чужое лицо исключает пару. Для портрета требуется подтверждение в нескольких кадрах; небольшой портрет на газете не считается полноценным человеком.
- Для тёмных кадров есть ограниченная коррекция экспозиции. Когда детектор лица не справляется, возможна проверка реальных пикселей по уверенно измеренным глазам и носу. Этот запасной способ может только подтвердить известную личность. Вид со спины без наблюдаемого лица сохраняет проверку тела.
- «Повторный анализ» теперь сбрасывает действительность кэша каждого выбранного видео и анализирует исходные кадры заново. Сбрасываются позы, допуск личности, лицевые проверки, RGB-последовательности и превью; после завершения сохраняется новый кэш для обычного анализа. Не выбранные видео сохраняют свой кэш. Переключатель нужно включить и нажать «Запустить анализ»; пока он включён, каждый запуск выполняется с нуля. Дополнительное расширение кандидатов сохраняется.
- Основной кэш измерений сохраняется. RGB-последовательности и проверка лиц имеют отдельные версии кэша; обновлённые правила не читают старые решения о лицах.

## Что установлено до остановки

Промежуточные прогоны на шести видео из D:/for_tests_pf проверяли Jack Sparrow, Steve Rogers, два Soldier Boy, Dean Winchester и Tobey Maguire. Проверка групп подтверждала две версии Soldier Boy вместе, исключала Steve из этого набора, объединяла два Soldier Boy с Dean как одного физического актёра Jensen Ackles и исключала Steve из несовместимого набора Jack + Steve. Это выбор физического человека, а не разделение ролей одного актёра.

Просмотр исходных кадров выявил копии сцен, возвращающиеся ракурсы, чужого человека в конце интервала и лицо на печатной фотографии. Эти случаи послужили основанием для дополнительных ограничений. При усилении проверки также появились пропуски настоящих тёмных/профильных кадров Jack; последний запасной способ распознавания направлен на их восстановление. Его отдельная проверка на исходных изображениях выполнена, однако завершающий полный прогон после этой правки остановлен по просьбе пользователя.

Пять автоматических наборов проверок прошли перед командой остановить проверки. После неё новые проверки не запускались. Окончательные количества пар для данной сборки не зафиксированы: числа ранних версий не выдаются за результат готового пакета.

## Ограничения

Полнота всех возможных параллелей на любых SCP и отсутствие регрессий не подтверждены. Поиск ограничен кандидатами, качеством лица и позы, квотой шотов и пределом выдачи. В группе рассматриваются уже допущенные главные люди каждого источника; второстепенный человек не становится целевым автоматически. Другие люди могут оставаться видны в полном кадре и превью. Мягкая проверка возвращающейся камеры и усиленная проверка лица могут отсеять полезный кандидат.

Часть сравнительных прогонов повторно использовала сохранённые исходные наблюдения RC16.3 через диагностический режим, а RGB-кадры и дополнительные лицевые измерения считывались из видео заново. Это не равнозначно свежему полному анализу всех файлов новым комплектом моделей. Исходные видео не изменялись.

## Исправление повторного анализа в RC16.4.1

Прежний переключатель повторно искал пары по сохранённым измерениям, что не соответствовало ожидаемому полному анализу. Теперь для каждого выбранного источника перед чтением измерений сохраняется новое поколение кэша. Оно входит в ключи всех производных измерений и превью; прежние ключи не используются, даже после перезапуска приложения или смены профиля. При неудаче сохранения сброса приложение сообщает ошибку вместо выдачи старого результата. Старые недействительные байты могут оставаться на диске до обычного вытеснения кэша. После исправления выполнена сборка; тесты и видео-прогоны не запускались в соответствии с предыдущей просьбой пользователя.
