# Parallel Finder 0.1.0-rc.18.2

## Русский

[-] Диалог обновления дожидается закрытия настроек или экспорта; повторные сообщения о состоянии не открывают уже открытый диалог заново.
[+] Настройки проверяются настоящими кликами: вкладки, крестик, перетаскивание, прокрутка и повторное открытие при появлении обновления.
[+] Добавлены мягкое появление страниц, плавный индикатор вкладок, более спокойное открытие диалогов и отклик кнопок. Анимации конечные и учитывают уменьшение движения.

Сохранены цвета, шрифты и компоновка приложения. Перед упаковкой выполняются общие тесты; после упаковки подписанный Portable проходит отдельную распаковку установщиком и проверку запуска.

## English

[-] Update prompts wait for Settings or Export to close; repeated state notifications no longer reopen an already visible dialog.
[+] Real input checks cover Settings tabs, close button, dragging, scrolling and reopening while an update arrives.
[+] Added soft page reveals, a sliding tab indicator, calmer dialog entrances and button feedback. All motion is finite and respects reduced motion.

Existing colors, typography and layout are preserved. General tests run before packaging; the signed Portable ZIP also passes updater extraction and an application health check afterward.
