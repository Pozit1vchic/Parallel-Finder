# Parallel Finder v0.1.0-rc.23.2

RC.23.2 исправляет общий lossless-экспорт из источников с разными параметрами.

- Вместо отказа при разных разрешениях автоматически подбирается общий холст по максимальным ширине и высоте. Маленькие кадры дополняются полями без уменьшения и растягивания под чужие пропорции. Для анаморфных источников учитывается соотношение сторон пикселя.
- Все части общего ролика используют согласованный lossless-кодек: AVC для обычного 8/10-битного YUV, FFV1 для высокой разрядности и прозрачности. Устранён риск несовместимой склейки из-за независимого выбора кодировщиков рабочими процессами.
- Разные форматы видео приводятся к общему представлению без сжатия с потерями. Перед склейкой проверяются размер холста, формат пикселей и параметры аудио.
- Разные частоты и количество каналов звука согласуются автоматически. Используется PCM; клипы без аудио получают тишину, если в общем ролике есть звуковая дорожка.
- Сохранены точная обрезка и временные метки кадров, включая переменную частоту кадров. Улучшена передача цветовых меток; параметры адаптации включены в проверку повторного использования подготовленных клипов.
- Описание lossless-экспорта обновлено на всех шести языках. MCP и инструкции для ИИ отражают автоматическую адаптацию потоков.

При совпадающих форматах проверки сравнивают декодированные пиксели и аудиосэмплы. Согласование разных цветовых форматов или частот звука меняет представление сэмплов: отсутствие сжатия с потерями не означает побитовое совпадение после такой адаптации. Поддержка FFV1 сторонними видеоредакторами, включая After Effects, отдельно не подтверждена.

Проверены смешанные разрешения, 8/10-битное видео, 12/24 FPS, 44,1/48 кГц, моно/стерео и клипы без звука. На синтетическом 3840×1600 10-bit видео проверены точная обрезка, склейка и сравнение декодированных кадров и звука. Все 10 тестовых целей прошли перед подготовкой выпуска; релизный процесс повторно проверяет сборку и подписанное обновление. Личные сценпаки в этом аудите не использовались: папка тестов была пустой.

Кэш анализа совместим; очищать его для обновления не требуется.
