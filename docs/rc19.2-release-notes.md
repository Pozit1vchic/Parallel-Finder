# Parallel Finder v0.1.0-rc.19.2

Изменения относительно RC19.1 / Changes since RC19.1

[+] Ускорен анализ: GPU-распознавание поз выполняется одновременно с обработкой лиц, ReID и трекингом предыдущих кадров.
[+] Поиск по внешности, подготовка кандидатов и сравнения матчера распараллелены; работа распределяется небольшими блоками между свободными потоками.
[+] Автоматический матчер использует доступные потоки CPU, до 256; добавлен отдельный статус подготовки кандидатов.
[+] Проверка повторяющихся ракурсов прекращается раньше, когда оставшиеся строки изображения уже не могут изменить решение.
[+] Ускорена подготовка изображений для моделей лиц с побитово одинаковым результатом; очередь кадров ограничена памятью.
[+] Создание превью 4K-видео использует проверенный NVIDIA-декодер с резервным CPU-путём.
[-] Убраны лишние обращения к общему счётчику и копирования путей для отклонённых сравнений; исправлена гонка при отмене конвейера.

В тестах относительно RC19.1: анализ Soldier Boy быстрее примерно на 25%, полный матчер на готовых данных шестичасового видео — на 5,7%. Полный запуск с пустым кешем завершён за 1 ч 8 мин; все 187 итоговых пар совпали по полям и порядку. Модель, частота анализа кадров, пороги и правила отбора сохранены. Условия замеров и ограничения — в `docs/rc19.2-validation.md`.

---

[+] Faster analysis: GPU pose inference overlaps face processing, ReID and tracking of preceding frames.
[+] Appearance retrieval, candidate preparation and matcher comparisons run in parallel, with small work blocks assigned to idle workers.
[+] Automatic matching uses available CPU threads, up to 256; candidate preparation has its own status.
[+] Returning-camera checks stop earlier once remaining image rows cannot change the decision.
[+] Faster face-model image preparation with bitwise identical output; frame queues have a memory bound.
[+] 4K preview generation uses validated NVIDIA decoding with CPU fallback.
[-] Reduced shared-counter contention and path copying for rejected comparisons; fixed a pipeline cancellation race.

Tests against RC19.1: about 25% less analysis time on Soldier Boy and 5.7% less matching time on cached observations of the six-hour input. The complete empty-cache run finishes in 1 h 8 min; all 187 final pairs retain every field and ordering. The model, frame sampling rate, thresholds and selection policy are preserved. Conditions and limitations are documented in `docs/rc19.2-validation.md`.
