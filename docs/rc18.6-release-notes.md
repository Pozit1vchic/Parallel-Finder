# Parallel Finder v0.1.0-rc.18.6

Изменения относительно RC18.5 / Changes since RC18.5

[-] Убрано резкое появление рамок после закрытия настроек: основной интерфейс сохраняет полное разрешение, размытие плавно исчезает вместе с диалогом.
[+] Отрисовка переведена в отдельный поток; анимации используют реальное прошедшее время и показывают больше промежуточных кадров.
[+] Размытие фона заранее подготавливается до показа окна и использует снимок вместо повторного размытия основного интерфейса на каждом кадре перехода.
[+] Добавлены проверки русской версии, повторного открытия настроек, завершения анимаций и отрисовки в покое; замеры плавности теперь учитывают реальные изменения анимации.
[-] Убрана повторная подпись прозрачности панелей и уточнено описание настроек оформления.

---

[-] Fixed borders appearing abruptly after closing settings: the workspace retains full resolution while the blurred backdrop fades out with the dialog.
[+] Rendering now runs on a separate thread; animations use elapsed time and display more intermediate frames.
[+] Backdrop blur is prepared before presenting the window and uses a snapshot instead of repeatedly blurring the workspace during transitions.
[+] Added Russian UI, settings reopening, animation completion and idle rendering checks; smoothness measurements now track actual animation changes.
[-] Removed the duplicate panel transparency label and updated the appearance settings description.
