# Parallel Finder 0.3.5

- У каждой пары есть номер, общий для списка результатов, сравнения и диалога замены. Счётчик неразобранных открывает следующую такую пару в текущем списке.
- Предзагрузка работает для ближайших 14 пар. Карточки персонажей появляются без ожидания декодирования всей галереи. Выбор на карточке запускает анализ, внизу находятся «Отмена» и «Все персонажи».
- На CPU с 12 и более логическими потоками автоматический режим совмещает декодирование и оценку позы. На двух отрывках Катнисс медиана четырёх контрольных запусков по двум вариантам составила 9,64 с последовательно и 8,64 с с предзагрузкой; число обработанных кадров и поз совпало.
- При замене стороны можно искать источник по номеру пары, движению или имени видео. Источники идут в порядке сортировки результатов. Выбранный момент А/Б сохраняется при смене донора.
- Классификация учитывает короткую фазу шага и отдельно показывает измеренную неподвижную стойку. Подтверждённый шаг больше не скрывается под неопределённой позой. Фильтр по отдельному движению включает пары, где оно входит в составной класс.
- «Копировать исходные потоки» сохраняет видео и звук без перекодирования с привязкой к ключевым кадрам. Точный экспорт 10-битных кадров использует FFV1 в MOV. Подписи номера пары, движения и стороны A/B можно встроить в кадр при обычном перекодировании.
- Фильтр «Не разобрано» показывает только соответствующие пары и позволяет отметить открытую пару вручную. Открытие карточки внутри фильтра оставляет её на экране до отметки.
- Статический режим группирует позы без оценки перемещения. Если движение не определено, результат может получить общий класс позы, когда признаки на обеих сторонах совпадают.
- Windows ищет DLL, которые CUDA и TensorRT загружают во время работы, в каталоге выбранного пакета ONNX Runtime. Точный экспорт MOV не переписывает закодированные данные ради размещения индекса в начале файла.

### Что ещё проверяется

- В диалоге замены есть фильтр по исходному видео. Счётчик «Не разобрано» открывает соответствующий список, где пары отмечаются вручную.
- Исправлено наложение элементов в окне выбора персонажа. Открытие полноразмерного фото после этой правки ещё требует проверки на исходном сценарии.
- Размер большого точного экспорта и точность классификации на полной пользовательской подборке отдельно не измерены.
