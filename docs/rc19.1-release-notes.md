# Parallel Finder v0.1.0-rc.19.1

Изменения относительно RC19 / Changes since RC19

[+] Ускорен отбор уникальных ракурсов: дорогая проверка кадров выполняется после проверки занятых сцен и других быстрых условий.
[+] Добавлен ограниченный кеш точных сравнений миниатюр сцен; сокращены копирование альтернатив и временные выделения памяти.
[-] Убран предварительный перебор ракурсов для всей массы кандидатов; счётчик отбора учитывает доступные альтернативы.

Пороги сравнения и проверки дублей сохранены. Ускорение относится к матчеру; этап распознавания видео остаётся отдельным.

---

[+] Faster unique-view selection: expensive frame verification follows occupied-shot and other inexpensive checks.
[+] Added a bounded cache of exact scene-thumbnail comparisons; reduced alternative copying and temporary allocations.
[-] Removed exhaustive upfront camera verification across all candidates; selection progress counts available alternatives.

Comparison thresholds and duplicate verification are preserved. This acceleration concerns matching; video recognition remains a separate stage.
