# v0.2.0 — черновик изменений

Этот файл подготовлен для будущей сборки. Релиз ещё не собран и не опубликован.
Перед публикацией нужно актуализировать ограничения по результатам проверок.

- Выбор персонажа расположен в центре окна; можно проверить несколько его
  появлений, изменить выбор и использовать сохранённый анализ.
- Улучшены выделение персонажа, работа с неопределёнными наблюдениями и
  сохранение выбора между файлами и перезапусками.
- Добавлены независимые фильтры ракурса головы и корпуса, пояснения направлений
  и корректное сохранение выбранных пунктов при смене языка.
- Исправлено использование устаревших настроек кэша при запуске анализа.
  Неудачное чтение настроек больше не позволяет затереть их значениями по умолчанию.
- Подробности неисправностей компонентов вынесены отдельно; после ошибки или
  отмены доступна повторная попытка без удаления проверенных загруженных файлов.

## Ограничения, которые нельзя скрывать при публикации

Общее качество классификации, сортировки и сопоставления на сложных сценах
остаётся предметом проверки. Не все видимые ракурсы удаётся уверенно определить.
Финальная проверка чистой установки, обновления и полного комплекта моделей
ещё требуется; зелёный набор тестов сам по себе её не заменяет.
