## Следующий порядок работ

1. Вернуть контрольную пару Солдатика 79/94 без ослабления проверки личности и без искусственного увеличения количества результатов. Последний измеренный результат: Dean 3/3 положительных, 0/3 отмеченных ложных; Soldier 2/3 положительных, 0/5 отмеченных ложных. Это маленькая контрольная выборка, не общая точность.
2. Отдельно исправить контекстное подавление дубликатов с учётом личности; проверить исходные видео, а не одни миниатюры.
3. Закрыть безопасность замены файлов экспорта и полную работу выбранного cache root с ошибками доступа.
4. Оптимизировать измеренный расход на превью; отдельно проверить реальные batches и одинаковые условия холодного/тёплого кэша.
5. Спроектировать процесс анализа для безопасного переключения runtime и полноценные визуальные признаки StaticFrameMatcher. Эти работы не относятся к быстрым косметическим исправлениям.
6. После проверок собрать portable/installer и итоговый patch-only ZIP относительно сохранённого пользовательского baseline, а не относительно старого Git HEAD.

Исторические пустые чекбоксы исходного плана не отражают текущий статус автоматически; использовать эту сводку вместе с журналом проверок. Коммит `a95a987` содержит согласованное общее состояние до небольшого прохода оформления.
