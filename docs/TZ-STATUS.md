# Состояние ТЗ — 1 октября 2026

Актуальная проверка кода, исправления и приоритеты — в [корневом AUDIT.md](../AUDIT.md), замеры трёх сценпаков и оставшиеся пропуски — в [отчёте RC.14](rc14-matcher-cache-audit.md). Эта сводка заменяет прежний список, где закрытые задачи продолжали числиться незавершёнными.

## Готово

- Превью внутри A/B для движения, статичной позы и головы; независимые кнопки сторон, общий запуск/пауза, остановка при смене пары. «Повтор» удалён; стрелки клавиатуры переключают результаты.
- Связь источников со статистикой: удаление материала очищает пары и остальные счётчики, старый анализ не возвращает их обратно.
- Модель по умолчанию YOLO26m; дальнейший выбор сохраняется отдельно от пути. Список моделей синхронизируется после загрузки подписей и не сбрасывается на YOLOv8n.
- Каталог 15 pose-моделей и отдельный runtime-каталог опубликованы и отвечают HTTP 200. Есть проверка размера/SHA-256, GitHub redirect и составных TensorRT-пакетов.
- Отбор требует identity-признаков; режим «Костюм / маска» и специальная функциональность удалены по запросу. В выпавших шотах восстанавливается локальная ведущая личность, без ослабления проверки между парами. Общая квота шота — три пары для движения и поз суммарно; слабые предположения о скрытых конечностях не подтверждают действие.
- Фоновый MP4-экспорт с отменой и безопасной заменой файлов; Exact/Fast и порядок нумерации. EDL/FCPXML/AEP JSX есть в библиотеке, но ещё не подключены к диалогу.
- Настройки анализа, языка и оформления — в AppData; English при отсутствии файла. При открытии оформления цвет соответствует сохранённому.
- Локальная версия готовится как **0.1.0-rc.14**; предыдущие RC.13-пакеты сохраняются. Версия в заголовке окна; упаковка проверяет запуск настоящего QML-интерфейса. Публикация выполняется отдельно.
- Источники внутри drag&drop; сортировка одним списком; стрелки не меняют сортировку и не зацикливают результаты; плавающая «↑ Вверх» и единый MP4 по таймкодам. UI/анимации и отключение переходов проверены тестами.
- Обычный повторный анализ переиспользует окна и PNG-превью. «Повторный поиск» расширяет кандидатов и выделяет уверенные короткие позы, не снижая пороги и не запуская YOLO заново при пригодном кэше. На трёх материалах получено 9→10 / 37→37 / 37→39 кандидатов обычного/расширенного поиска; это не общий precision/recall.
- Репозиторий очищен от локальных старых пакетов и логов, усилен `.gitignore`, обновлены README и генератор проверок. Обложка и SVG сохранены.

## Осталось

1. Управляемое завершение анализа, инспекции файлов и загрузок при закрытии приложения; отдельные регрессии всех этих сценариев.
2. Существенное повышение полноты на размеченных действиях, частично скрытых руках и разных ракурсах. Большие наборы других людей, полноценные визуальные/action-признаки и выбор целевого персонажа остаются отдельными работами; счётчик карточек их не заменяет.
3. Понятные пользователю ошибки записи кэша и длительные проверки диска/лимита. PNG входят в обычный ограниченный кэш и собственные временные сеансы уже очищаются; повторное удаление старого сеанса не ломает cache hit.
4. RAII для временных ORT-ресурсов; замеры памяти, handles, FPS/DPI и реальной batch-производительности.
5. Полное скачивание/активация CUDA/TensorRT кнопкой, установка и анализ на чистой Windows и разных GPU. HTTP 200 манифеста не заменяет эти проверки.
6. Подключение дополнительных экспортных форматов к интерфейсу, проверка импорта в редакторы и отдельная проверка комплектности/лицензий стабильного выпуска.
