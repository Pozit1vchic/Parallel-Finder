# Parallel Finder v0.1.0-rc.22.5

RC.22.5 улучшает сортировку сцен по позе и делает расхождения классификатора явными.

- Добавлена общая группа «Сидит / лежит»: сидячие и лежачие фрагменты собираются вместе и не перемешиваются с подтверждёнными стоячими позами.
- Добавлены отдельные группы «Разные положения тела» и «Положение тела не определено». Если одна сторона пары уверенно сидит/лежит, а другая стоит, пара отделяется; если поза подтверждена только с одной стороны, она не попадает в группу стоячих.
- Для крупных планов, где не видны ноги, добавлен консервативный разбор позы встроенной AVA SlowFast моделью. Учитываются выбранный человек, исходный клип, точные границы и отсутствие склейки; временная и замороженная оценки должны согласоваться. Сомнительные случаи остаются неопределёнными.
- AVA-разбор теперь выполняется и для неподвижных совпадений, а не только для движущихся сцен. Обычная проверка ходьбы по-прежнему требует полного торса.
- Пары с уверенно различающимися действиями получают отдельную группу, вместо того чтобы теряться среди неопределённых совпадений. Неподтверждённые действия остаются неопределёнными.
- Новые группы доступны в фильтрах, сортировке, ручной классификации, экспорте и MCP. Ручной тип пары сохраняется приоритетным.
- Улучшены автоматические проверки классификации позы, надёжности видеоизмерений и сохранения результатов матчера.

Проверка: полный набор CTest (10/10) проходит на локальной сборке Windows. Геометрические и AVA-пороговые случаи покрыты искусственными тестами; независимая размеченная оценка точности позы на полном наборе `D:\for_tests_pf` не выполнена. Этот релиз не подтверждает профессиональную полноту поиска параллелей или целевой скорости анализа 520 тысяч кадров.
