# Parallel Finder v0.1.0-rc.18.4

Изменения относительно RC18.3 / Changes since RC18.3

[+] Выбор цвета перенесён к галочке каждой пары; убраны фильтры движений, групп, цветов и общий блок «Цвет и группа».
[+] В экспорте добавлен порядок цветов с перестановкой вверх/вниз; он определяет порядок отдельных клипов и записей JSON/CSV/TXT.
[+] Вкладки настроек растянуты до краёв диалога с сохранением оформления.
[+] Уменьшены задержка подготовки кадров и нагрузка размытия фона; сохранён режим отрисовки, исправивший зависания Windows.
[+] Добавлены тесты выбора цвета, порядка экспорта и обновления кадров во время анимации диалога.

---

[+] Moved color selection next to each pair’s checkbox; removed movement, group and color filters and the shared color/group editor.
[+] Added an adjustable color order in export; it controls individual clip numbering and JSON/CSV/TXT record order.
[+] Settings tabs now extend across the full dialog width while keeping the existing style.
[+] Reduced frame scheduling delay and backdrop blur cost while retaining the render loop that fixed Windows stalls.
[+] Added pair color selection, export ordering and dialog animation frame tests.
