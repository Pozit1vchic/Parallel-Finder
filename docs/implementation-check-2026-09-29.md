# Проверка исправлений 29 сентября 2026

## Матчер

Подавление соседних результатов теперь сверяет личность на каждой стороне пары.
Совпадающие сцены и таймкоды не схлопываются, когда достоверные face/body признаки
показывают разных людей. При отсутствующих признаках действует прежняя логика;
смена trackId сама по себе не считается доказательством другого человека.

48 unit тестов MotionMatcher прошли. На контрольной YOLO26m с CUDA и ReID:

- Dean: 7 результатов; все 3 положительных якоря найдены, 0/3 отмеченных
  отрицательных приняты. Время анализа около 55 секунд.
- Soldier: 83 результата; 3/3 положительных, 0/5 отмеченных отрицательных.

Отдельный проход Dean с YOLO11n дал 17 результатов, 0/3 положительных якоря и
1/3 ложных принятых. Эти две модели дают разные результаты; тест новой NMS не
является доказательством общего улучшения качества. Расширенная разметка и
полноценное сравнение статичных кадров остаются открытыми.

## Экспорт

Для MP4 и текстовых проектов уже существующий файл заменяется системной операцией
без его предварительного удаления. Если установка нового файла не удалась,
прежний путь сохраняется. Тесты проверили успешную замену и отказ при занятом
каталогом пути. FCPXML прошёл проверку ссылок на 2, 3, 5 и 7 источников.
Групповая атомарность двух файлов AEP отдельно не реализована.

## Превью

Декодер результата теперь открывается один раз на исходный файл в рамках анализа
и переиспользуется для следующих временных отметок. Отдельный тест проверяет
переходы вперёд и назад по времени и сравнивает кадры с новым декодером.
Это сокращает число открытий файла; влияние на общее время анализа пока не
измерено на одинаковых холодных/тёплых условиях.

Общий CTest после исправлений: 5/5. Portable и installer rc.4 собраны; SHA-256
трёх файлов выпуска сверены, CPU и UI smoke из staged portable прошли без
путей разработчика. Проверка установки у друга и загрузки GPU runtime остаётся.
