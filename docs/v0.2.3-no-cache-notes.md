# v0.2.3 — настройка кэша

- Добавлена настройка «Создавать кэш». По умолчанию выключена.
- Когда кэш выключен, постоянные данные анализа не читаются и не записываются; каждый новый запуск выполняет анализ заново. Временные превью используются для отображения результатов.
- Когда кэш включён, сохраняются прежние возможности повторного использования анализа. Существующие кэши не удаляются.
