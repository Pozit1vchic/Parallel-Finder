# Parallel Finder v0.1.0-rc.20.3

- Исправлен фон окна экспорта на больших экранах: растягивающая интерфейс размытая подложка заменена затемнением без изменения размеров элементов. Окно корректно центрируется при изменении размера приложения.
- После отмены и повторного открытия экспорта старое сообщение об отмене сбрасывается. При новом запуске очищается статус предыдущей операции.
- Подготовка границ сцен выполняется перед каждым клипом, а не для всего списка до первого файла. Интерфейс показывает подготовку клипа, прогресс обработки и финальную сборку общего ролика.
- Повторяющиеся отрезки с одинаковыми настройками кодируются один раз: для остальных пар сохраняются копии готового файла с нужной нумерацией. Общий ролик по-прежнему исключает точные дубликаты.
- В список качества добавлен вариант «Без потери качества · без перекодирования» для отдельных клипов и общего MP4. Исходные видео и все звуковые дорожки копируются без повторного кодирования.
- Общий ролик без потери качества проверяет совместимость исходных потоков. Несовместимые видео не перекодируются автоматически; приложение предлагает отдельные клипы или режим с перекодированием.
- Долгая финальная сборка больше не прерывается только из-за общей длительности в две минуты: ограничение применяется к отсутствию продвижения. При сохранении готового ролика отображается прогресс.
- Добавлена кнопка «Снять цвет»: с выбранных пар, а при отсутствии выбора — со всех видимых пар. Действие поддерживает существующую отмену изменений.

В режиме без перекодирования границы отрезков зависят от ключевых кадров. «Максимальное» остаётся режимом с перекодированием и не гарантирует отсутствие потерь. Формат и ключи кэша анализа сохранены; повторный анализ для обновления не требуется.

Проверки: все 7 тестовых целей прошли; отдельно проверен настоящий интерфейс с 600 парами и шириной окна 3440 пикселей, отмена и повторное открытие экспорта, снятие цвета и обновление оформления. Для отдельных клипов и общего ролика совпали хэши исходных видео- и аудиопакетов, включая обе звуковые дорожки тестового видео. Проверено повторное использование одинаковых клипов без изменения их содержимого. Полный экспорт шестичасового видео не измерялся; количественное ускорение такого экспорта не заявляется.
