# Parallel Finder v0.1.0-rc.18.5

Изменения относительно RC18.4 / Changes since RC18.4

[-] Проверка ускорителей при запуске перенесена в отдельный процесс с пониженным приоритетом; ONNX Runtime больше не загружается в процесс интерфейса для этой проверки.
[-] Подготовка первого графического кадра выполняется до показа окна; анимация появления начинается после подготовки.
[-] Проверка выбранного провайдера перед анализом использует готовый статус и не запускает повторную инициализацию в интерфейсе.
[+] Добавлены проверки запуска нового процесса, первого открытия настроек, ошибок, таймаута и отмены проверки ускорителей.

---

[-] Startup backend probing now runs in a separate process at lower priority; the UI process no longer loads ONNX Runtime for this check.
[-] The first graphics frame is prepared before presenting the window; the entrance animation starts after preparation.
[-] Analysis provider validation uses the published status instead of initializing the runtime on the UI thread.
[+] Added fresh-process startup, first settings opening, probe failure, timeout and cancellation checks.
