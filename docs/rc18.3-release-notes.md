# Parallel Finder v0.1.0-rc.18.3

Изменения относительно RC18.2 / Changes since RC18.2

[-] Сохранение оформления и параметров анализа перенесено в фон; частые изменения объединяются без потери настроек разных разделов.
[-] Исправлена остановка анимаций на Windows: используется устойчивый режим отрисовки Qt с сохранением ускорения видеокартой.
[-] Проверки статуса GPU больше не запускают долгую инициализацию из интерфейса; устаревший обход добавленных видео прекращается при изменении списка.
[+] Добавлены заметное появление основного окна и диалогов, подъём содержимого и плавное переключение страниц.
[+] Вкладки настроек получили цельную поверхность и рамку; уменьшены лишние отступы, усилены контуры кнопок без смены палитры.
[+] Добавлены проверки отзывчивости, сохранения на медленном диске и геометрии вкладок.

---

[-] Appearance and analysis settings now save in the background; rapid changes are coalesced without overwriting other sections.
[-] Fixed stalled Windows animations using a reliable Qt render loop while retaining GPU acceleration.
[-] GPU status getters no longer start slow initialization from the UI; obsolete video inspection stops when the source list changes.
[+] Added visible window and dialog entrances, content reveals and smooth page transitions.
[+] Settings tabs now have full surfaces and borders; tightened spacing and clearer button outlines preserve the existing palette.
[+] Added responsiveness, slow-storage persistence and tab geometry checks.
