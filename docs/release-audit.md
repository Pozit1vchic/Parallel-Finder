# Проверки перед публикацией

Это действующий список проверок, а не журнал старых RC. Текущее состояние кода: [AUDIT.md](../AUDIT.md). Опубликованный RC20: [изменения](rc20-release-notes.md).

1. Выполнить тесты ядра, интерфейса, Discord, обновлений и размеченные регрессии матчера.
2. Проверить настоящий интерфейс из подготовленной папки с корректными Qt DLL и plugins.
3. Проверить отмену анализа, подстройки, экспорта и загрузок; проверить освобождение временных папок и память после работы.
4. Проверить чистую Windows, загрузку моделей и доступные GPU-провайдеры. Локальная машина не заменяет разные устройства.
5. Проверить комплектность зависимостей, лицензии моделей/runtime и подписи обновления; состав пакета описан в [инструкции релиза](../tools/release/README.md).
6. Проверить архивы, контрольные суммы и запуск portable/установщика до публикации.

Ускорение измерять отдельно для cold/warm; точность — на размеченных парах, а не по количеству карточек. Не переносить старые замеры на новый бинарник без повторения проверки. Скрипт упаковки выполняет собственные обязательные проверки; этот список их не отключает.
