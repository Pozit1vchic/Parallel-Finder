- Полный CTest: 14/14 наборов, 0 ошибок, 134,41 секунды.
- Интерфейс: 58 проверок прошли, 7 дополнительных проверок пропущены.
- Запуск упакованного окна изолированно от окружения разработки: успешно.
- Подписанное обновление из Portable ZIP: 3 проверки прошли, 0 ошибок,
  0 пропусков. Проверена подпись закреплённым открытым ключом.
- Контрольные суммы всех пяти файлов из `SHA256SUMS.txt` совпадают.
- Настоящая чистая установка Setup в `Чистая установка 日本語`: все 1983
  файла совпадают с манифестом, приложение сообщает `v0.2.0 smoke ok`,
  окно отображается.
- Настоящее обновление Setup с `0.1.0-rc.23.2` в `Обновление 日本語`:

  установки в реестре удалена.

Проверки запускались на текущей Windows 11 из отдельной рабочей папки,
с очищенными путями Qt и PATH без инструментов разработки. Это не проверка
на отдельной чистой виртуальной машине. Установленный базовый runtime
проверен на CPU; эти результаты не подтверждают работу всех GPU-компонентов.

## Исправление, найденное перед выпуском

Первый кандидат падал при загрузке ONNX Runtime из пути с кириллицей и
японскими символами. Чтение переменных окружения переведено на Windows
Unicode API. Добавлена проверка в отдельном дочернем процессе: до исправления
она падала, после исправления проходит. Первый кандидат
`0.2.0-621368d2` заменён проверенной сборкой `0.2.0-499a2218`.
