# Parallel Finder v0.1.0-rc.18.8

Изменения относительно RC18.7 / Changes since RC18.7

[-] Устранён большой расход памяти при поиске границ сцен: длинные сценпаки больше не создают полный массив HSV-кадров.
[+] Ускорены выбор основного персонажа и проверка повторяющихся ракурсов без ослабления фильтров личности и дубликатов.
[+] Кеш кадров стал компактнее; убраны повторное чтение только что подготовленных данных и лишнее декодирование соседних кадров; проверка ракурсов на CPU выполняется параллельно с общим ограничением потоков.
[-] Вместо неподвижного «Анализируем движение» отображаются этапы подготовки, работа матчера и проверка лиц со счётчиками; число сцен обновляется до завершения поиска.
[+] Добавлены время обработки и отмена выбора персонажа; расширены проверки памяти, скорости, совпадения результатов и русского/английского интерфейса.
[-] Статичные результаты больше не запускают видеоплееры заранее; декодеры A/B создаются при воспроизведении.

---

[-] Fixed excessive memory usage during scene detection: long scene packs no longer allocate HSV frames for the entire video.
[+] Accelerated main-character selection and recurring-camera checks while retaining identity and duplicate safeguards.
[+] Added a compact footage cache and removed immediate rereading of freshly prepared observations and redundant decoding of nearby frames; CPU camera-view checks run in parallel with a shared thread budget.
[-] Replaced the lingering “Analyzing motion” label with preparation, matcher and face-verification stages and counters; scene counts update before matching finishes.
[+] Added elapsed time and cancellation during character selection, plus memory, speed, result-preservation and Russian/English UI checks.
[-] Still results no longer initialize video players in advance; A/B decoders are created when playback is requested.
