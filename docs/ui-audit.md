# UI audit — stage 5

Дата проверки: 2026-09-12

Проверка сопоставляет QML с `docs/design.md`, `DESIGN.md`,
`docs/ui-reference-research.md` и текущим контрактом `AnalysisController`.

## Что соответствует контракту

- Рабочее окно сохраняет три колонки с одинаковой шириной боковых rail и общим
  внешним inset; rail прокручивается вместо обрезания.
- Центральная область остаётся единственным крупным comparison-stage. Статистики
  собраны в одну hairline-разделённую полосу.
- Все девять параметров matcher связаны с `MotionMatcherParams`, показывают
  значение рядом с контролом и имеют подсказку при наведении. Порог детектора
  сцен вынесен отдельным контролом на главный экран, как требует прототип.
- Sources, folder picker, provider, quality profile, checkboxes, filters, sort,
  Prev/Next и export подключены к реальным свойствам/сигналам, а не являются
  декоративными элементами.
- Результат содержит A/B preview, source name, реальные timecode, duration и
  четыре маркера таймлайна; есть zoom, pan и fullscreen.
- Settings и Export — собственные movable overlays с dimmed backdrop, deep shadow,
  Escape-close и клавиатурным фокусом. Settings разделены на вкладки Analysis /
  Appearance; в них оставлены только provider/model/cache и language/font/
  transparency соответственно. Scene/matcher controls находятся на главном
  экране, а не дублируются в настройках.
- Theme-токены централизованы. Appearance меняет язык, шрифт и прозрачность
  поверхностей; импорт/экспорт тем, aura и motion-настройки не являются частью
  текущего UI-контракта.
- Введён единый `L10n`-контракт для пользовательских строк, включая язык,
  сообщения импорта/экспорта и доступность.

## Исправления этой проверки

1. Убраны последние hard-coded accessibility labels таймлайна.
2. `PfSlider` получил короткие hover-tooltip и описания для всех девяти
   matcher-параметров.
3. В Settings добавлен настоящий язык интерфейса с сохранением; отсутствующие
   английские ключи безопасно используют русское значение вместо отображения
   имени ключа.
4. Плейсхолдеры путей и статусы theme import/export переведены в `L10n`.
5. Удалены aura, курсорное motion field, постоянные анимации и декоративный
   blur. Empty-state оставлен статичным, чтобы не маскировать рабочее состояние.
6. Slider binding больше не перезаписывает значение на стартовом `valueChanged`:
  запись в `AnalysisController` выполняется на пользовательском `moved`.
7. Пути из Qt FileDialog нормализуются через `QUrl::toLocalFile()` и удаление
  лишнего `/` перед диском Windows; тот же контракт используется при анализе,
  предпросмотре и выборе папки.
8. Превью результатов сохраняются и передаются в QML как `file:///` URL, чтобы
   Windows-пути не интерпретировались как URL-схема диска.
9. ONNX Runtime ограничивает probe API версией, заявленной загруженной DLL
   (DML 1.17 больше не печатает ложное предупреждение о запросе API 18).

## Остаточные ограничения перед release

- Английский словарь покрывает текущие пользовательские строки. Динамические
  backend-статусы проходят через `L10n.status`; сообщения об ошибках сохраняют
  диагностическую часть пути/исключения.
- Визуальную полировку следует принять на живом окне с реальным источником:
  offscreen smoke-тест подтверждает загрузку QML, но не заменяет просмотр кадров
  и overlay на целевом DPI.
- `5b` (Qt deploy) и `6` (GPU bundle, performance validation, final release
  audit) остаются отдельными релизными стадиями.
