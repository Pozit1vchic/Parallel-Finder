# Parallel Finder 0.1.0-rc.18.1

## Русский

[+] Диалог обновления перетаскивается за заголовок и остаётся в пределах окна.
[+] Плавные переходы высоты, состояния и прогресса с учётом уменьшения анимаций.
[+] Скачанные пакеты повторно используются после закрытия диалога, проверки и перезапуска приложения; подлинность проверяется перед использованием.
[+] Приостановленная загрузка сохраняется и продолжается через HTTP Range; если сервер игнорирует Range, загрузка безопасно начинается целиком. Старые скачанные ZIP также используются после проверки.
[+] Проверка запускается без искусственной задержки; известное сохранённое обновление показывается сразу при включённой автоматической проверке.
[-] Исправлен откат успешного обновления из-за разного написания версии с префиксом v: новый updater сравнивает SemVer, приложение сохраняет написание подписанного запроса для совместимости с RC17.1.
[-] Stable использует обычные релизы GitHub, Beta — обычные релизы и Pre-release; суффикс rc больше не исключает обычный релиз из Stable.
[-] Пропущенная версия не предлагается снова после перезапуска, смены канала или ручной проверки; уведомление возвращается для следующей версии.

Номер в заголовке и сведения о версии берутся из запущенной сборки и меняются после успешной установки и перезапуска. Для старого клиента RC17.1 версия в подписанном манифесте должна совпадать с тегом GitHub буквально; сборка поддерживает параметр GitHubTag.

## English

[+] Draggable update dialog, bounded to the application window.
[+] Smooth height, status and progress transitions respecting reduced motion.
[+] Authenticated downloaded packages survive dialog closure, repeated checks and application restarts.
[+] Paused downloads resume using HTTP Range, with a safe full-download fallback; verified legacy cached ZIPs are reused.
[+] Startup checks have no artificial delay; known cached updates are shown immediately when automatic checks are enabled.
[-] Fixed successful-update rollback caused by optional v-prefix differences; restart acknowledgements remain compatible with RC17.1.
[-] Stable includes ordinary GitHub releases, Beta includes ordinary releases and prereleases, regardless of rc tag spelling.
[-] Skipped versions stay skipped across restarts, channel changes and manual checks; newer versions are offered again.

Window title and version information follow the running build after a successful update and restart. RC17.1 requires the signed manifest version to match the GitHub tag literally; use the GitHubTag build parameter.
