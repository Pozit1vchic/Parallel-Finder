# Parallel Finder v0.1.0-rc.22.1

RC.22.1 combines the RC.22 work with follow-up fixes and UI refinements requested after RC.21.

- Added movement-classified result groups, with custom manual groups, multi-selection, sorting and export order support. Automatic labels come from measured pose signals; ambiguous or unsupported motion can remain unclassified.
- Added pair repair tools: replace one side from another result, remove a side while keeping the remaining moment, combine two single moments, and undo edits. A dedicated pair-settings menu brings the related actions together.
- Improved duplicate suppression for repeated detections from the same source scene, and refined matcher candidates for camera/profile views. This does not establish complete back-view recall.
- Added a six-language settings page (Russian, English, Kyrgyz, Kazakh, Ukrainian, Turkish), English as the first-run language, animated flag reveals, and a selector limited to installed fonts.
- Expanded appearance controls with separate solid-color and gradient palettes, custom gradients, consistent application-wide accents, live appearance updates, and distinct settings and theme controls. Settings follow the resized application window.
- Simplified the analysis controls into Fast, Balanced and Maximum processing modes; moved language and multi-selection preferences into settings and reduced incidental interface text and scroll decoration.
- Refined export naming, output-folder persistence, format and quality choices, and transition titles. Export starts with ultra-parallel preparation enabled while preserving clip order and exact selected boundaries.
- Fixed exact lossless montage audio concatenation: the concat manifest no longer drops the first 1024 PCM samples from each prepared MOV. Real 4K HEVC tests confirmed matching decoded video frames, audio samples and combined output.
- Measured parallel clip preparation on eight independent 720p clips: 1.37× faster in Fast, 2.19× in Exact and 1.71× in Lossless. These synthetic measurements are not a full 4K analysis benchmark.
- Added a local MCP server with controls for analysis, results, classification, pair trimming and export, plus the root `SKILL.md` for compatible AI agents.
- Preserved the analysis cache across upgrades; no cache deletion or rebuild is required.

## Validation and known limits

The release build is checked with the full CTest suite, a packaged-application startup check and signed-update archive verification. Real-source lossless tests compare decoded 4K video frames and audio through separate and combined exports. The real-video matcher smoke test runs only on the supplied `D:\for_tests_pf` footage.

Motion classification and matching remain under active improvement. Full recall across rear views, classification accuracy across varied edits, and the target of analyzing 520,000 frames in 30–40 minutes have not been established by a representative benchmark. CUDA availability depends on the installed runtime and model files.
