## Обновление v0.2.5

- Исправлен застывший экран «Подготавливаем кадры для матчера» после завершения счётчика: проверка повторных появлений и подготовка превью персонажей теперь показывают свой этап и прогресс.
- Ускорена проверка повторных появлений: исключены заведомо неподходящие пары сцен и повторные вычисления внутри сравнений. Пороги совпадений сохранены.
- Кнопка **«Параллели без выбора персонажа»** перенесена вниз окна выбора персонажа. Поиск продолжается на уже подготовленных данных без повторного анализа видео.

Проверены несколько видео с выключенным кэшем, выбор персонажа и продолжение без выбора, интерфейс и регрессии поиска совпадений. Ускорение всего анализа на длинных видео отдельно не измерялось.
