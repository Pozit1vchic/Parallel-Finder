# Полный технический аудит текущего состояния

Дата аудита: 15.09.2026. Проверены QML, C++ bridge, model store, provider
preflight, pose/re-ID pipeline, matcher, cache, exporters, сборка и smoke-тесты.

## 1. Матчер и идентичность

Исправленная цепочка теперь не сравнивает один случайный кадр со всеми:

* детектор сохраняет все person tracks, а не только dominant;
* в одном исходнике допускаются только окна одного `trackId`;
* окна той же сцены и близкие временные интервалы отбрасываются;
* статика фильтруется по средней дельте суставов, доле активных переходов и
  диапазону траектории;
* валидный результат требует непрерывного temporal run и минимальной длины
  окна, после чего считается band-constrained DTW;
* overlapping results проходят NMS/deduplication;
* body-ReID добавляет cosine gate и 20% appearance-веса, если OSNet/FastReID
  ONNX действительно установлен.

Ограничение: без совместимой ReID-модели режим остаётся `pose-only`; это
намеренный прозрачный fallback, а не обещание распознавания личности.

## 2. Модель и провайдер

* Runtime-контракт модели — статический batch-1 ONNX 640×640 с 17 keypoints.
  `.pt`, batch-8/16 и произвольный output-граф не считаются совместимыми.
* Провайдер из Settings реально передаётся в `PoseEstimator`. Ручной `cuda`,
  `tensorrt` или `dml` проходит preflight и при недоступности возвращает
  понятную ошибку; тихой подмены на CPU нет. `auto` использует probe-цепочку.
* Каталог имен исправлен на `yolov8*`, `yolo11*`, `yolo26*`; рядом с каждым
  именем UI показывает наличие файла. Выбор отсутствующей модели блокирует
  запуск анализа на время скачивания.
* `ModelStore` принимает только HTTPS, следует безопасным HTTPS-редиректам,
  возобновляет `.part`, проверяет size/SHA-256 и атомарно устанавливает файл.
  Manifest поддерживает `models`/`assets`, `url`/`downloadUrl` и
  `size`/`sizeBytes`.

## 3. UI/UX и состояния

* Оперативные параметры остаются в левом rail; Settings не дублирует пресеты.
  Advanced-секция закрыта по умолчанию.
* QML использует scrollable rail, editable slider fields, focus/accessibility
  свойства и единые Theme/L10n-токены. Пустое состояние не изображает рабочий
  анализ и не содержит ауры.
* В каталоге модели отображаются `✓ установлена`/`↓ скачать`, имя текущей
  загрузки, процент и сообщение об ошибке. Кнопка Start недоступна, пока
  модель скачивается или не установлена.
* Стоп-кадры, timecode, track/re-ID метаданные и экспортные поля уже проходят
  через result records; QML smoke проверяет загрузку статического модуля.

## 4. Cache и данные

`PFCACHE1` хранит versioned motion windows. Ключ включает исходник, метаданные,
выбранную модель, provider и optional ReID-модель; после смены модели старые
признаки не выдаются за новые. Запись атомарная, размер ограничен настройкой,
эвикция детерминированная.

## 5. Реальная проверка

Проверено локально:

```text
cmake --build build/ucrt64-release --parallel 4   PASS
ctest --test-dir build/ucrt64-release --output-on-failure   3/3 PASS
```

Локальный каталог содержит 15 YOLO `.pt` и `yolo26m` batch-1/batch-8 ONNX.
У репозитория `Pozit1vchic/Parallel-Finder` на момент аудита нет GitHub
Releases, поэтому реальный скачанный asset и body-ReID inference ещё нельзя
проверить end-to-end. После публикации Release нужно выполнить сценарий из
`docs/models.md`: загрузить все ONNX и `manifest.json` одним набором.

До публикации manifest приложение имеет HTTPS fallback по имени файла и честно
показывает, что SHA/size не подтверждены. Для production-релиза manifest
обязателен.
