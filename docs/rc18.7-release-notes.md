# Parallel Finder v0.1.0-rc.18.7

Изменения относительно RC18.6 / Changes since RC18.6

[-] Цвет, шрифт, язык и прозрачность фона за настройками обновляются сразу, без закрытия диалога; снимок обновляется только на время изменения оформления.
[-] Убрано принудительное использование альтернативного таймера анимаций: Qt снова синхронизирует переходы с экраном, а задержка подготовки кадров уменьшена для мониторов с высокой частотой обновления.
[-] Исправлен снимок фона при открытии настроек во время анимации запуска.
[+] Добавлены проверки изменения цвета по изображению, перетаскивания и прокрутки настроек, остановки отрисовки в покое и диагностика активного окна с журналом графического адаптера.

---

[-] The backdrop updates immediately when changing accent, font, language or panel transparency, without closing settings; snapshot refresh runs only during appearance changes.
[-] Removed the forced alternative animation clock: Qt again synchronizes transitions with the display, with a shorter frame preparation delay for high refresh rate monitors.
[-] Fixed the backdrop snapshot when opening settings during the startup animation.
[+] Added image-based accent checks, settings drag and scroll checks, idle rendering checks and foreground profiling with graphics adapter logs.
