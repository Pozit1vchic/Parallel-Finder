# v0.2.2

- Ускорена упаковка крупных кэшей: данные окон обрабатываются параллельно с учётом настройки потоков, а большие копии данных при обработке нескольких файлов устранены. Формат кэша сохранён.
- Исправлено чтение кэшей персонажей со служебными данными больше 16 МиБ: существующие кэши теперь можно повторно использовать.
- При обработке нескольких видео показываются имя и номер текущего файла.
- Проверены четыре сохранённых кэша Katniss: два из них прежняя версия не могла прочитать из-за лимита размера. После исправления все четыре читаются и повторно упаковываются побайтно без изменений. Полный повторный анализ всех видео не проводился, поэтому нельзя утверждать, что любая задержка устранена.
