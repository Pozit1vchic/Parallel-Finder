# Разбор найденных пар

Результаты можно просматривать в списках «Все», «Избранное» и «Удалённые». Крестик справа вверху карточки убирает пару из основного списка; в «Удалённых» её можно восстановить. Удалённые пары не попадают в экспорт и лист находок. Звезда добавляет пару в избранное.

## Подстройка на таймлайне

«Подстроить пару» открывает независимые таймлайны A и B. Две ручки задают начало и конец фрагмента. Кнопки масштаба помогают выбрать границы, а ±1 кадр сдвигает весь диапазон на один кадр с учётом FPS исходника. Перетаскивание конца показывает последний кадр выбранного фрагмента. Превью декодируются вне потока интерфейса, с ограничением размера и одним текущим запросом.

До «Применить» изменения остаются черновиком. После применения просмотр, MP4 и лист находок используют выбранные границы; автоматическое уточнение сцены и ограничение длительности больше не переопределяют ручной диапазон. «Вернуть исходную пару» отменяет подстройку, сохраняя цвет и избранное.

## Горячие клавиши и мультивыбор

Третья вкладка настроек — «Горячие клавиши». Сочетания сохраняются между запусками; занятые сочетания нельзя назначить второй раз. У каждого действия две независимые привязки в колонках «Клавиша 1» и «Клавиша 2», с компактными кнопками высотой 28 пикселей и очисткой каждой привязки. Для удаления по умолчанию назначены Delete и Backspace.

| Действие | По умолчанию |
| --- | --- |
| Предыдущая / следующая пара | ↑ / ↓ |
| Удалить / восстановить | Delete, Backspace |
| Избранное | F |
| Отметить для экспорта | X |
| Воспроизвести / приостановить | Space |
| Подстроить | A |
| Экспорт отмеченных | Ctrl+E |
| Лист находок | Ctrl+Shift+E |
| Выделить всё / снять выделение | Ctrl+A / Ctrl+Shift+A |
| Снять цвет / назначить цвет | 0 / 1–5 |

«Включить мультивыбор» включает обычное выделение: Ctrl переключает отдельные пары, Shift выбирает диапазон в текущем порядке списка. Цвет, избранное и удаление применяются к выбранным парам. Сочетания разбора не срабатывают при редактировании полей и в открытых диалогах.

Избранное, удалённые пары и ручные диапазоны относятся к текущим результатам анализа; новый анализ создаёт новый список.

## Лист находок

PNG содержит парные ряды A/B с именами источников, таймкодами реально декодированных кадров и сходством пары. Можно включить весь видимый список или только отмеченные пары и выбрать 1, 3 или 5 кадров на каждой стороне. Большой список разбивается на страницы по четыре пары. Каждая страница записывается атомарно; при отмене уже завершённые страницы остаются в папке.

## Качество экспорта

В точном режиме доступны «Максимальное» (14), «Высокое» (18, по умолчанию), «Баланс качества и размера» (22) и свой целевой битрейт 1–500 Мбит/с. Значения качества переводятся в параметры конкретного кодировщика: CRF для x264, CQ для NVENC, CQP для AMF, global_quality для QSV. Одинаковое число не гарантирует одинакового результата на разных кодировщиках.

Обычные клипы сохраняют разрешение исходника. Монтаж нормализует геометрию и FPS по первому исходнику. AAC использует 256 кбит/с. Точный режим перекодирует видео, поэтому абсолютное сохранение качества не обещается. Для исходного видеопотока без потерь доступен быстрый режим: он копирует поток, а точность границ зависит от ключевых кадров. В нём настройки качества отключены.

Установщик и релиз в рамках этой правки не собирались. Проверка выполняется тестовыми целями.

## Проверка

Реальное видео Soldier Boy: холодный и повторный прогоны с автоматическим поиском вспомогательных моделей дали по шесть пар. Отдельный сценарий разбора проверяет Delete/Backspace, восстановление, избранное, обновление кадров при сдвиге на кадр, отсутствие изменения пары до применения, экспорт PNG и сохранение ручного диапазона 7,5 секунды в MP4.

Геометрия списка проверяется по реальным элементам: следующая карточка начинается ниже нижней границы предыдущей с зазором как минимум четыре пикселя. Высота строки определяется метриками шрифта и наличием цветовой метки; анимация смещения не записывает координаты раскладки.

Для экспорта проверены параметры всех четырёх кодировщиков, качество и свой битрейт на декодируемых клипах, отмена и зависание FFmpeg, монтаж разных исходников и сохранение разрешения/FPS/аудио на Soldier Boy. Аппаратный запуск AMF и QSV на этом ПК отдельно не проверялся.
