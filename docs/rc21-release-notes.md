# Parallel Finder v0.1.0-rc.21

- Добавлена ручная сортировка результатов по собственным группам с выбором мышью, Ctrl/Shift и страницами. Ручные группы учитываются при сортировке и экспорте, не подменяя автоматическую классификацию.
- Добавлено редактирование состава параллели: замена стороны клипом из другой пары, удаление одной стороны с сохранением оставшегося момента и объединение двух одиночных моментов. Правки можно отменить; устаревшая оценка сходства после изменения не показывается.
- Добавлены превью для ручной сборки пары и анимированная связь исходных карточек с результатом. Отключение анимаций учитывается.
- Удалённые стороны исключаются из превью, экспорта и монтажных файлов; экспорт одиночного момента использует оставшиеся границы.
- Ускорена подготовка и нарезка экспортных клипов ограниченной очередью параллельных задач для быстрых, точных и lossless-режимов. Порядок результатов сохраняется, одинаковые клипы переиспользуются, отмена останавливает очередь.
- Добавлена возможность сохранить клипы отдельно без потерь, если общий lossless-монтаж несовместим с исходными потоками; приложение не переключает такой экспорт скрытно на формат с потерями.
- Исправлены переполнение панели управления воспроизведением на узком окне и перекрытие списка источников кнопками.
- MCP расширен до 32 инструментов при включённом управлении, включая ручную сортировку, изменение сторон, экспорт, статус и локальные превью. Добавлен корневой `SKILL.md` с описанием безопасной работы инструментов.
- Расширены проверки матчера на сдвиг изображения: на контрольной паре Soldier Boy сохранены все 38 ранее найденных интервалов.
- Ускорена обработка кадров в широкоэкранном 4K; проверенные кадры совпали по пикселям, временным меткам и геометрии.
- Добавлены инструкции по MCP, очистке только известных сборочных папок и локальному хранению исследовательских данных.

Это промежуточный выпуск. На контрольном наборе из 38 пар классификатор оставил 11 неоднозначных результатов без типа движения; профессиональная точность всех действий и полнота поиска со спины пока не заявляются. Сохранение всех хороших параллелей проверено на контрольных интервалах, но требуется более широкий независимый набор. Цель анализа 520 тысяч кадров за 30–40 минут и двукратное ускорение полного анализа не подтверждены одинаковым полным прогоном. Lossless-монтаж может требовать совместимых потоков; отдельные клипы можно сохранить без потерь.

Кэш анализа не требуется удалять. Формат сохранённых измерений не менялся.
