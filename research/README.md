# Локальные исследования и проверки

В этой папке хранятся локальные отчёты, исходные измерения, изображения для
визуальной проверки и изолированные тестовые кеши. Эти данные не входят в Git
и архив исходников приложения. Они могут содержать имена пользовательских
видео, изображения из них и результаты длительных вычислений.

Повторно используемые небольшие обезличенные проверки кода находятся в
`tests/fixtures`, инструменты воспроизведения — в `tools/benchmark`,
поддерживаемые инструкции — в `docs`. Не переносить сюда код приложения и
не удалять наблюдения только ради чистого `git status`.

`build/ucrt64-release` — единственная текущая рабочая сборка. Опубликованные
пакеты находятся отдельно в `release`; модели и пользовательский кеш не
являются временными сборками. Для проверки временных каталогов упаковки
используется `tools/release/clean-builds.ps1`, по умолчанию без удаления.
