# Model assets

Веса моделей **не хранятся в репозитории**. Приложение использует ONNX-экспорт
YOLO-pose, а не исходные Ultralytics `.pt`. При выборе отсутствующей модели UI
показывает `↓ скачать`, загружает её из GitHub Release с тегом `v0.1.0-models` и проверяет
размер/SHA-256 из `manifest.json` до атомарной установки.

Установленные файлы хранятся автоматически в:

```text
%LocalAppData%\ParallelFinder\models
```

### Подготовка release из D:\YOLO_Download_Project\models

```powershell
$env:PYTHONPATH = 'D:\PythonLibs'
python tools\model_export\export_pose_release.py `
  --input-dir 'D:\YOLO_Download_Project\models' `
  --output-dir 'D:\Parallel-Finder\release-models'
```

Скрипт экспортирует каждый `*pose*.pt` в статический batch-1 ONNX 640×640 и
создаёт рядом `manifest.json`. Создайте Release в
`Pozit1vchic/Parallel-Finder` и загрузите **все** `.onnx` плюс `manifest.json`
как assets одного релиза. Имена должны совпадать с manifest: приложение берёт
их по адресу `releases/download/v0.1.0-models/<filename>`.

Для разработки можно задать `PF_MODEL_ROOT` на папку с ONNX-файлами, а
`PF_MODEL_PATH` — на конкретный файл. Ни `.pt`, ни `manifest.json` не нужно
класть в установочную папку вручную.

### Модель ориентации головы

Рабочая сборка также использует `head-pose-6drepnet360.onnx`. Проверенная версия,
размер, контрольная сумма и условия подготовки входа указаны в
`head-pose-6drepnet360.json`. Сохраните ONNX и исходную MIT-лицензию
`head-pose-6drepnet360.LICENSE` рядом с метаданными в этой папке. Экспорт из
исходных определений автора: `tools/benchmark/export_head_pose360.py`.

`tools/release/stage-classifier-model.ps1` проверяет модель и лицензию перед
копированием в `models` сборки. Сценарии развёртывания и упаковки вызывают его
автоматически. Отсутствующая или неподходящая модель останавливает упаковку;
существующий отличающийся файл не перезаписывается. Проверка экспорта и загрузки
модели не заменяет проверку точности классификации на реальных сценах.

Веса игнорируются Git; метаданные и документация остаются в репозитории.

`ava-slowfast-r50.onnx` — сохранённая модель AVA для нового слоя классификации
действий по видео. Подключена к классификации проверенных пар: пока дополнительная
категория — ходьба, с проверкой обеих сторон, видимости выбранного человека,
непрерывности сцены и отличия от неподвижного контрольного фрагмента. Наблюдения
хранятся в отдельном версионированном кеше; исходный кеш поз не изменяется.
Сценарий упаковки проверяет и копирует модель, метаданные и лицензию.
Это ещё не готовый профессиональный классификатор всех действий. Подробности:
`docs/video-action-audit-2026-10-14.md`.
