# Аудит Parallel Finder — 30 сентября 2026

Проверено рабочее дерево после `811ad4e`, включая изменения этого аудита. Последняя сборка приложения — **0.1.0-rc.7**. Здесь разделены обнаруженные риски, уже исправленные недостатки и проверки, которые ещё не выполнялись. Исторические отчёты в `docs` описывают свои даты и не заменяют этот файл.

## Что проверено

Просмотрены конфигурация сборки/CI, QML и связи с контроллерами, фоновые задачи, загрузка моделей/runtime, владение ресурсами ONNX, дисковый кэш, превью, экспорт, упаковщики, документация и состав Git. Это обзор кода и воспроизводимые проверки, а не инструментальный замер утечек или точности на большой выборке.

- **Release-сборка:** успешна, актуальные исходники не требуют пересборки бинарника.
- **CTest:** 5/5 наборов, 20,82 с: ядро/сервисы/GPU, UI, запуск приложения, изоляция запуска, регрессии матчера.
- **108** отслеживаемых C++/QML файлов, из них **19 QML**.
- Запрещённых гарнитур в QML, ошибок синтаксиса PowerShell и отслеживаемых логов/весов/сборок: **0**.
- `git diff --check` прошёл.
- Два опубликованных каталога GitHub отвечают HTTP 200: `v0.1.0-models/manifest.json` содержит 15 pose-моделей; `runtime-v1/providers.json` содержит CUDA, TensorRT и DirectML, TensorRT — двумя частями.
- Обложка README и все SVG сохранены без изменения содержимого.

Автоматическая часть сохранена локально в `build/audit-checks.md`. Она создаётся командой `pwsh -File tools/benchmark/audit_project.ps1`; при ошибке проверки скрипт возвращает ошибку, а при `-SkipTests` явно помечает тесты как пропущенные. Реальные GPU-пакеты целиком и GitHub CI в этом проходе не запускались.

## Оставшиеся риски и недочёты

| Приоритет | Наблюдение и место | Последствие / следующая проверка |
|---|---|---|
| **P1** | `AnalysisController.cpp` и `AppInfo.cpp`: загрузки, инспекция файлов и анализ создают `QThread::create` с захватом `this`; при выходе явно ждут только export worker и provider scan | Нет единого управления завершением остальных задач. Возможны незавершённые операции и обращения при уничтожении singletons; падение в этом аудите не воспроизводилось. Нужны управляемое завершение и тест выхода во время каждой операции |
| **P1** | Проверка качества матчера опирается на небольшие контрольные наборы Soldier/Dean и эвристики лица, тела и контекста | Регрессии подтверждают конкретные пары, но не общую полноту/точность. Нужна расширенная разметка с другими людьми, масками, одинаковой одеждой, профилями и дальними планами |
| **P2** | `savePreview()` в `AnalysisController.cpp` пишет PNG в `%TEMP%/ParallelFinder/previews`; лимита и очистки сессий нет | Превью копятся вне выбранного cache root и его лимита. Нужна очистка по сессиям, сохраняющая изображения открытых результатов |
| **P2** | `analysisCache->put(...)` игнорирует возвращённый результат и `cacheError` | Анализ работает, но при недоступной папке или полном диске пользователь не узнаёт, почему каждый запуск снова медленный. Нужны явный статус и тест ошибок записи |
| **P2** | `gpu/src/Inference.cpp`: ресурсы ORT освобождаются вручную между выделениями `std::vector`/`std::string` | Обычные ветки ошибок закрыты, но исключение выделения памяти может обойти освобождение. Нужны RAII-владельцы; обнаруженная утечка в обычном прогоне не заявляется |
| **P2** | `ExportDialog.qml` предлагает только FFMPEG/JSON/CSV/TXT, хотя библиотека поддерживает EDL/FCPXML/AEP JSX | Эти форматы пока недоступны обычному пользователю. README теперь разделяет UI и возможности библиотеки |
| **P2** | Пакеты и runtime проверялись локально, но не полностью на чистой Windows и нескольких GPU | Нужны установка/удаление, скачивание CUDA/TensorRT кнопкой, настоящий анализ и повторный запуск без среды разработки |
| **P3** | Настройки путей сборки имеют локальные значения по умолчанию в release-скриптах | Чужая машина требует указать параметры. Они вынесены в README, но автоматическое обнаружение инструментов можно улучшить |
| **P3** | Разросшийся `AnalysisController.cpp` совмещает каталог моделей, анализ, кэш, превью, настройки и экспорт | Дальнейшие изменения труднее локализовать и проверять. Выделять сервисы стоит по одному, сохраняя текущие регрессии |

Анализаторы cppcheck/clang-tidy в окружении не обнаружены. Не измерялись FPS, число GUI/GPU handles, динамические утечки, DPI 125–200% и многочасовые сессии. Обязательства по зависимостям и весам моделей требуют отдельной проверки перед стабильным распространением; этот обзор кода её не заменяет.

## Что уже работает, а не является открытой ошибкой

- Сброс результатов и числа пар при удалении источника; устаревший анализ не возвращает прежние счётчики.
- Последняя модель сохраняется отдельно от файла; UI больше не сбрасывает список на YOLOv8n при обновлении каталога.
- Превью статичных поз, головы и движения внутри A/B; отдельные кнопки сторон и общий запуск; остановка при смене пары; стрелки клавиатуры.
- Фоновая очередь MP4-экспорта, отмена, безопасная замена готового файла; текстовые экспортёры проверены тестами.
- Загрузка моделей/runtime учитывает GitHub redirect, проверяет размеры и SHA-256; ошибку `Operation canceled` от промежуточного HTTP 302 исправили ранее.
- Подавление соседних дубликатов учитывает identity-признаки. Исторические задачи об отсутствии этой проверки уже закрыты.

Последняя документированная проверка реальных видео на YOLO26m: Soldier **3/3** положительных и **0/5** отмеченных ложных, Dean **3/3** и **0/3**. Это результаты предыдущего видеопрогона, который **не повторялся** в данном аудите; [источник измерений](docs/implementation-check-2026-09-29.md), [исправление отбора головы](docs/matcher-selection-2026-09-29.md).
